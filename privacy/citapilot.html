Política de privacidad — __MSG_extName__

Versión 1.0.0 · todas las políticas

Qué datos maneja

__MSG_extName__ funciona en el navegador del usuario. Los datos que la extensión crea (ajustes, historial, elementos guardados) se almacenan con chrome.storage en el propio equipo. No existe ningún servidor operado por nosotros: no recibimos, no almacenamos y no vendemos datos de los usuarios.

Servicios de terceros

Si el usuario configura una clave de API propia, el contenido necesario para la operación solicitada se envía directamente desde su navegador al proveedor que él haya elegido. Nosotros no intermediamos ni vemos ese tráfico. Los destinos posibles son:

  • aistudio.google.com
  • api.anthropic.com
  • api.deepseek.com
  • api.groq.com
  • api.mistral.ai
  • api.openai.com
  • api.together.xyz
  • console.anthropic.com
  • console.groq.com
  • console.mistral.ai
  • generativelanguage.googleapis.com
  • openrouter.ai
  • platform.deepseek.com
  • platform.openai.com

La clave de API se guarda únicamente en el almacenamiento local del navegador y nunca se envía a nadie más que al proveedor correspondiente. El tratamiento que cada proveedor haga de los datos se rige por su propia política de privacidad.

Datos que NO recogemos

  • No hay analítica, telemetría ni identificadores de seguimiento.
  • No se recogen datos de salud, financieros, de autenticación ni comunicaciones personales con destino a servidores nuestros.
  • No se venden ni se transfieren datos a terceros con fines publicitarios.
  • No se usan los datos del usuario para entrenar modelos.

Permisos solicitados y para qué

  • sidePanel — Mostrar la interfaz principal en el panel lateral de Chrome.
  • activeTab — Leer el contenido de la pestaña activa solo cuando el usuario abre la extensión y actúa sobre ella.
  • scripting — Inyectar el script de análisis en la pestaña que el usuario indica, bajo su gesto explícito.
  • storage — Guardar los ajustes y los datos del usuario en el navegador. No se sincronizan con ningún servidor propio.
  • contextMenus — Añadir la acción de la extensión al menú contextual del clic derecho.

Control del usuario y borrado

Todos los datos residen en el navegador. Se eliminan por completo desinstalando la extensión, o desde chrome://settings/siteData. Las funciones de exportación permiten al usuario llevarse sus datos en CSV, JSON o Markdown cuando la extensión las ofrece.

Uso limitado

El uso de la información recibida se ajusta a la política de Uso Limitado de la Chrome Web Store: los datos se emplean únicamente para ofrecer la funcionalidad visible al usuario.
