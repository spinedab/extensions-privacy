# Políticas de privacidad — Chrome Extensions Suite

Páginas de política de privacidad de las extensiones de la suite, publicadas con
GitHub Pages. Generadas automáticamente desde los manifests y el código de cada
extensión; no editar a mano — se regeneran con `tools/gen-store-assets.js` en el
repositorio principal y se sincronizan con `tools/publish-privacy.sh`.
